# Security policy

The tool handles untrusted files. Report path handling, output overwrite, parser resource exhaustion, redaction, unintended execution/network activity, or trust-boundary flaws privately to hello@huzaifa.io with subject `Cross-Agent Handoff security`. Use a synthetic minimal reproduction, version/commit and runtime; never include tokens, real histories or company/customer data. Do not disclose unpatched vulnerabilities in public issues.

The 0.x line is experimental; no service-level response time or security certification is promised. Imported claims are not verified facts. Redaction is user-selected, not guaranteed secret discovery. Expiry is a signal and named-file purge is not secure erasure. No native vendor authentication or automatic execution exists. File hashes are context, not signatures. See README for supported limits and threat boundaries.
