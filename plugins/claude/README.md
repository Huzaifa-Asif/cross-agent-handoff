# Cross-Agent Handoff local plugin

See [installation and usage](docs/platform-plugins.md), [privacy](docs/privacy.md), and [security](SECURITY.md).

This self-contained package uses Python 3.11+ and contains no third-party runtime dependencies. If you extracted a host ZIP, skip the source-build step in the installation guide and use this directory as the plugin path. Directory listing and real-host UI verification are separate from a successful package build.
