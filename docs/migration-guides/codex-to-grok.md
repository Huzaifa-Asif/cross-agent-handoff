# Codex to Grok

1. Export the required Codex sessions as Markdown/text where possible.
2. Choose **Full Migration**, source **Codex**, and the reader matching the file.
3. Process locally; review records, omissions, and sensitive data.
4. Choose destination **Grok**, save the reviewed library, and verify the files.
5. Paste or upload the relevant references where supported by the selected Grok product.

No account connection or native session restoration occurs.
