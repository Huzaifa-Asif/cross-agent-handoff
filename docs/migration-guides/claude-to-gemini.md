# Claude to Gemini

1. Download the official Claude export.
2. Choose **Full Migration**, source **Claude**, and the Claude JSON reader.
3. Process locally, review omissions, and redact anything you should not share.
4. Select destination **Gemini**, save the portable library, and verify the files.
5. Supply only relevant reviewed references to Gemini using the upload or context controls available to your account.

Gemini may separately support native import of certain original archives. The generated portable library is not a Gemini native-import archive.
