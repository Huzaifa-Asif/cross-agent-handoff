# Claude to Cursor

1. Download your official Claude data export.
2. Choose **Full Migration**, source **Claude**, and **Claude JSON export layout**.
3. Process into a new local library; review records, omissions, and sensitive fields.
4. Select destination **Cursor**, save the reviewed portable library, and verify it.
5. Open the relevant references in Cursor or attach them to a chat explicitly. Keep them as inert project references, not automatic rule files.

This does not create Cursor rules or restore a native Claude session.
