# Cursor to Codex

1. Export or select authorized Cursor transcripts/documents. There is no verified full-account Cursor reader.
2. Choose **Full Migration**, source **Cursor**, and the matching document or generic reader.
3. Process into a new local library; review records, omissions, and opaque files.
4. Redact sensitive fields, choose destination **Codex**, save the library, and verify it.
5. Attach the index and relevant records to a Codex chat as reference context.

This does not recreate Cursor sessions or silently copy repository content.
