# Grok to Cursor

1. Export or select Grok conversations/documents you are authorized to move.
2. Choose **Full Migration**, source **Grok**, and a matching supported reader.
3. Process into a new local library; review records, omissions, and opaque files.
4. Redact sensitive content, choose destination **Cursor**, save, and verify it.
5. Add relevant reviewed references to Cursor explicitly, not as project rules.

Native Grok history and unselected project files are not transferred.
