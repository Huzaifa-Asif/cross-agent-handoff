# Codex to Gemini

1. Export Codex sessions as Markdown/text where available.
2. Choose **Full Migration**, source **Codex**, and the matching document or experimental JSONL reader.
3. Process a new local library, review omissions, and redact sensitive fields.
4. Choose destination **Gemini**, save the portable library, and verify it.
5. Upload only relevant reviewed references to Gemini using the controls available to your account.

The portable output is not a Gemini native-import archive.
