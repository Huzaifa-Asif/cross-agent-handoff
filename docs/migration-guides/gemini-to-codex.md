# Gemini to Codex

1. Export or select the Gemini conversations/documents you may move.
2. Choose **Full Migration**, source **Gemini**, and the matching document or generic reader.
3. Process locally, review records and omissions, and redact sensitive fields.
4. Select destination **Codex**, save the reviewed portable library, and verify it.
5. Attach the index and only relevant references to a Codex chat.

A verified full-account Gemini parser and native Codex history importer are not claimed.
