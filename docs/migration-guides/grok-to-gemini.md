# Grok to Gemini

1. Export or select authorized Grok conversations/documents.
2. Choose **Full Migration**, source **Grok**, and the matching document or generic reader.
3. Process locally, review records and omissions, and redact sensitive fields.
4. Select destination **Gemini**, save the reviewed portable library, and verify it.
5. Upload only relevant references using the controls available to your Gemini account.

The portable library is not a Gemini native-import archive.
