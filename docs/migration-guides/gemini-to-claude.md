# Gemini to Claude

1. Export or select Gemini conversations/documents you are authorized to move. A verified full-account Gemini parser is not available.
2. Choose **Full Migration**, source **Gemini**, and a supported document or generic format.
3. Process into a new local library and review omissions and opaque files.
4. Redact sensitive content, select destination **Claude**, save, and verify the library.
5. Attach only relevant reviewed references to Claude; do not install them as persistent instructions.

Native Gemini session history and hidden settings are not transferred.
