# Grok to Codex

1. Export or select authorized Grok conversation documents.
2. Choose **Full Migration**, source **Grok**, and the reader matching the files.
3. Process locally; review omissions carefully because full-account Grok parsing is not claimed.
4. Redact sensitive fields, select destination **Codex**, save, and verify the library.
5. Attach the index and only relevant reviewed records to a Codex chat.

The process transfers reviewed references, not a native Grok session.
