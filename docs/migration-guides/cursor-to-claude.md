# Cursor to Claude

1. Export or select the Cursor transcripts and documents you are authorized to move. A verified full-account Cursor parser is not available.
2. Choose **Full Migration**, source **Cursor**, and **Documents** or a supported generic format matching the files.
3. Process a new local library and review opaque files and omissions carefully.
4. Redact sensitive content, select destination **Claude**, save, and verify the reviewed library.
5. Attach relevant references to Claude explicitly; do not convert them into automatic instructions.

Cursor rules, editor state, and unselected repository files are not migrated.
