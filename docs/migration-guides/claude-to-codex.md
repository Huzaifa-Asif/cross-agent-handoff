# Claude to Codex

1. Request and download your official Claude data export.
2. In Cross-Agent Handoff, choose **Full Migration**, source **Claude**, and **Claude JSON export layout**.
3. Select the export and a new local library folder, confirm the authorized long-term move, and start processing.
4. Review normalized conversations and omissions. Redact fields you should not share.
5. Choose destination **Codex**, confirm review, save the portable library, and verify the saved files.
6. In a new Codex chat, attach the index and only the relevant Markdown or JSON records. Ask Codex to treat them as reference context.

The library does not recreate Claude chats in Codex or transfer Claude hidden memory.
