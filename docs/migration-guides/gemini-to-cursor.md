# Gemini to Cursor

1. Export or select authorized Gemini conversations/documents.
2. Choose **Full Migration**, source **Gemini**, and a reader matching the selected format.
3. Process a new local library and review records, opaque files, and omissions.
4. Redact sensitive content, choose destination **Cursor**, save, and verify the output.
5. Add relevant reviewed references to Cursor explicitly, not as automatic rules.

This does not restore native Gemini sessions in Cursor.
