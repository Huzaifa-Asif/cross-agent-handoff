# Codex to Cursor

1. Export Codex work as Markdown/text; use internal JSONL only with the experimental reader.
2. Choose **Full Migration**, source **Codex**, and the reader matching the selected file.
3. Process locally, review omissions and records, and redact sensitive content.
4. Select destination **Cursor**, save the reviewed library, and verify it.
5. Add relevant files to Cursor as explicit context. Do not write them into automatic Cursor rule files.

Repository files are not copied unless you separately select and share them.
