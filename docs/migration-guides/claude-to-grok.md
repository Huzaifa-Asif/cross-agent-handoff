# Claude to Grok

1. Download your official Claude export.
2. Choose **Full Migration**, source **Claude**, and the Claude JSON reader.
3. Create and process a new local library, then review records and omissions.
4. Redact sensitive fields, select destination **Grok**, save, and verify the reviewed library.
5. Paste or upload only the references supported by your Grok product and account.

The tool does not connect the accounts or promise a native Grok history importer.
