YOUR FILES. YOUR DECISION.

Nothing moves until you choose.

  1. 01

    Choose your context

    For Task Hand Off, write the goal and useful context. For Full Migration, download an official export on your provider’s site. There is no AI-account login in this tool.

  2. 02

    Build locally

    Select files in the desktop app or CLI. The migration engine processes batches and records what it could read.

  3. 03

    Review, then share

    Inspect records and omissions, redact sensitive fields, and explicitly share chosen references with your next assistant.

A portable library, with honest limits. This does not recreate another tool’s chat sidebar or hidden memory. Missing attachments, deleted chats and settings absent from an export cannot be recovered. Destination upload and context limits still apply.

Start with the desktop app

  1. Choose your OS. The download above is for Apple Silicon Mac (M1 or newer). The Windows x64 candidate passed native Windows CI; no Windows release is available yet.
  2. Install Python 3.11 or newer from python.org. Node and npm are not needed for the desktop app.
  3. Extract the ZIP and open Cross-Agent Handoff.app. This Mac app is unsigned and not notarized. Follow macOS security guidance without disabling protections.
  4. Choose Task Hand Off or Full Migration in the candidate. The existing v1.0.0 download calls these modes “One task” and “Move my library”. Use Task Hand Off for one piece of work; use Full Migration for a deliberate long-term move with your selected official export.

Close and reopen the app after installing Python. Review every saved reference before sharing it yourself. The app never signs in to your AI account or restores hidden memory.

Developer CLI instructions (optional)

Task Hand Off: developer commands

Run from the extracted source folder. Review the Markdown before attaching it in your next assistant.

python3 handoff.py new --goal "Prepare the launch plan" --provider claude --domain marketing --context "Budget approval is pending" --output task.json
python3 handoff.py inspect task.json
python3 handoff.py export task.json --provider codex --output handoff-codex.md

Full Migration: developer example

Start with the included example. The plan prints a checkpoint digest; use it for the automatic batch run in the guide.

python3 handoff.py migrate plan examples/migration-history.json --workspace migration-work --provider generic --format generic-json --confirm-long-term-migration
